# 🎮 ECHOES OF DARKNESS

Полноценная 3D хоррор-игра на выживание, работающая прямо в браузере. Создана с использованием Three.js.

## 🚀 Как запустить

1. Скачайте файлы `index.html`, `script.js` и `README.md`.
2. Положите их в одну папку.
3. Откройте `index.html` в любом современном браузере (Chrome, Firefox, Edge).
   *Или загрузите репозиторий на GitHub и включите GitHub Pages.*

## 🎯 Управление

- **WASD**: Перемещение
- **SHIFT**: Бег (тратит выносливость)
- **Мышь**: Обзор
- **F** или **ЛКМ**: Фонарик
- **E**: Взаимодействие (подбор предметов)
- **ESC**: Пауза / Меню

## 📖 Сюжет и Геймплей

Вы просыпаетесь в темном процедурно-генерируемом лабиринте.
- **Цель**: Найти 5 золотых ключей, чтобы выбраться.
- **Враг**: Красное существо патрулирует коридоры. Если оно увидит вас — начнется погоня.
- **Экономика**: Собирайте серебряные монеты, чтобы покупать улучшения в магазине (скорость, лечение).

## 🛠 Технологии

- **Графика**: Three.js (WebGL)
- **Звук**: Web Audio API (процедурная генерация звуков)
- **Архитектура**: Модульная система на чистом JS (ES6+)

## ⚠️ Требования

- ПК с видеокартой, поддерживающей WebGL.
- Браузер не старше 2020 года.
